Applications / 420 Wallet

your entry point to the ecosystem.

420 Wallet is intended to be the primary user interface for accounts, signing, assets and application access across 420 Integrated.

accounts & signing

The wallet manages account access and presents transactions for user approval. Recovery material and private keys should never be shared with applications, support contacts or other users.

assets & activity

Users will be able to view native $420 balances, supported assets and transaction history while cross-checking activity through 420 Explorer.

application connections

Genesis applications and later ecosystem apps are intended to request wallet connections and signatures through explicit user approval rather than silently receiving account authority.

network configuration

Official chain metadata, RPC endpoints and release links will be published only after the corresponding builds and network configuration are qualified.

Release downloads, production endpoints and final network values are intentionally omitted until qualification.
