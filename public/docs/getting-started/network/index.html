Getting started / Network

connect to the network.

420 Integrated uses an EVM-compatible execution environment. Wallets and applications will connect using published network metadata and RPC endpoints.

network values

The official reference will publish the network name, chain ID, native currency symbol and decimals, RPC endpoints, explorer URLs and any required service endpoints.

RPC access

420RPC is intended to provide the standard public developer and wallet gateway for reads and transaction submission. Capacity, rate limits and endpoint policy will be published with deployment.

verify before connecting

Do not copy RPC URLs or chain IDs from random social posts or third-party sites. Verify values against the official 420 Integrated documentation and Registry.

Exact testnet and production values are intentionally omitted until the corresponding network configuration is locked and qualified.
