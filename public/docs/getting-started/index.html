getting started.

This guide defines the shortest path from first contact with 420 Integrated to using the network safely. Live production values will be filled in as genesis configuration is finalized.

1. understand the network

420 Integrated is an EVM-compatible blockchain ecosystem with shared services for identity, naming, registries, payments, governance, interoperability, AI, media and applications.

2. install 420 Wallet

420 Wallet will be the primary user entry point for accounts, signing, assets and application access. Official download and verification links will appear here once release builds are qualified.

3. connect to the network

Chain ID, RPC endpoint, explorer URL, native currency metadata and network configuration will be published here when the testnet and genesis network values are locked.

4. acquire test assets

The faucet is testnet-only. Test tokens and test assets will be available for development and qualification without implying production value.

5. verify everything

Use 420 Explorer, 420 Registry and official documentation to verify network addresses, contracts, applications and service endpoints before interacting with them.

Current status: documentation structure is live, but deployment-specific values are intentionally withheld until the corresponding network services are qualified.
