Operators / Validators

operate a validator deliberately.

Validator operation combines key custody, node health, participation rules and careful lifecycle management.

key separation

Keep validator signing keys isolated from routine administration credentials. Backup procedures should protect recovery material without duplicating active signing authority across hosts.

participation

Operators should monitor synchronization, peer health, signing activity, missed duties and validator status. Qualification documentation will publish the exact participation and staking procedures for the genesis network.

maintenance

Plan maintenance around network expectations. Avoid simultaneous primary and recovery instances using the same signing authority unless the protocol explicitly supports a safe handoff mechanism.

lifecycle

Joining, pausing, rotating infrastructure and exiting must follow the canonical validator lifecycle once those procedures are locked. Never infer production timing rules from temporary testnet behavior.
