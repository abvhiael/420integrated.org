Applications / App Store

discover ecosystem apps.

420 App Store is intended to be the canonical discovery surface for approved ecosystem applications, releases and integration metadata.

what it should expose

Application identity, publisher records, supported networks, release channels, permissions, documentation links and verification state should be visible before installation or connection.

trust model

The App Store should rely on canonical Registry and Identity records rather than treating presentation metadata as proof of authenticity.

distribution

Where application binaries or packages are distributed, checksums, signing information and release provenance should be available alongside the listing.

Public listing rules, moderation policy and release-channel requirements will be published before production launch.
