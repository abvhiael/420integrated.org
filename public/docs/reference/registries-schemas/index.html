Reference / Schemas

registries & schemas.

Shared registry keys and record formats let independent applications resolve the same ecosystem identities, services and metadata consistently.

registry records

Reference entries will document canonical keys, record ownership, version fields, lifecycle state and the meaning of each value exposed through shared registries.

identity & names

Identity and naming schemas will define required fields, normalization rules, uniqueness constraints and how applications should handle missing or superseded records.

application schemas

Where applications publish structured metadata, this reference will describe the schema version and the minimum fields needed for interoperable discovery and validation.

Only stable, versioned schema definitions will be marked canonical. Experimental fields may appear elsewhere but should not be treated as public contract.
