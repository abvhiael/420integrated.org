Applications / Payments & Exchange

move value through shared rails.

420 Pay, 420 Swap and 420 Bridge are intended to provide payment, exchange and interoperability paths that other ecosystem applications can reuse.

420 Pay

420 Pay handles application-facing payment and settlement flows while keeping authorization and accounting boundaries explicit.

420 Swap

420 Swap provides asset-exchange execution for supported markets and is intended to be reused by other applications rather than reimplemented in each product.

420 Bridge

420 Bridge carries cross-chain transfer and attestation flows for supported external networks, subject to the verification rules of each bridge path.

user verification

Before signing, users should verify the asset, amount, destination, route, expected output and any approval requested by the transaction.

Supported assets, routes, fees, liquidity sources and production addresses will be documented only after their deployment configuration is qualified.
