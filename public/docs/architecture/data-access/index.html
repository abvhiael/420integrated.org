Architecture / Data & access

data, indexing & access.

Raw chain execution becomes useful to applications through a data-access layer built around RPC, indexing, exploration, search and analytics.

420RPC

420RPC is intended to provide the standard network gateway for reads, transaction submission and wallet or application connectivity.

420Indexer

420Indexer normalizes chain activity into queryable application data so explorers, analytics services and dApps do not need to reconstruct every view directly from raw blocks.

consumer surfaces

420 Explorer, Search, Analytics and Notifications are intended to reuse the same canonical data pipeline while presenting different user and developer views.

Public endpoint URLs, schemas, rate limits and service-level expectations will be published when the corresponding infrastructure reaches deployment qualification.
