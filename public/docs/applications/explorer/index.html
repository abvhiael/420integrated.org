inspect what happened on-chain.

420 Explorer is intended to make blocks, transactions, addresses, contracts and network activity readable without requiring command-line tooling.

transactions

Transaction views will expose status, sender, destination, value, fees, block inclusion and decoded activity where supported.

blocks & addresses

Block pages provide execution context and transaction lists, while address pages provide balances and activity histories derived from indexed chain data.

contracts

Explorer views are intended to surface verified contract metadata, events and application relationships where canonical records are available.

verification

Use Explorer together with 420 Registry and official documentation when confirming contract addresses, deployments and network activity.

Public explorer URLs and deployment-specific references will be published after the relevant infrastructure is qualified.
