Applications / Participation

staking & governance.

420 Stake and 420 Governance provide the user-facing path for network participation, validator economics and protocol decision-making.

420 Stake

420 Stake is intended to surface validator participation, delegation rules where supported, reward visibility, lock or unbond timing, and slashing-related risk in a form users can verify before committing assets.

420 Governance

420 Governance is intended to expose proposals, voting windows, execution state and the authority boundaries of network governance. Genesis policy does not assume unrestricted stake-weighted control over every system function.

verify the current rules

Participation parameters can materially affect risk. Users should verify live validator requirements, reward policy, governance scope and emergency controls against the official network reference before acting.

Final validator thresholds, reward values, voting parameters and production contract addresses will be published only after genesis qualification.
