infrastructure first.

The project is designed as a connected stack rather than a collection of isolated apps. Network services, identity, discovery, payments, governance and application infrastructure are intended to work together from genesis.

01 / CHAIN

Blockchain foundation

An EVM-compatible base layer with native network services and infrastructure designed around the 420 Integrated application ecosystem.

02 / PROTOCOLS

Shared primitives

Identity, naming, registries, payments, rights, storage, messaging, randomness, governance and other common capabilities can be reused across applications.

03 / APPS

Composable ecosystem

Wallets, explorers, markets, media, games and community tools can connect to the same underlying network instead of rebuilding the same infrastructure repeatedly.
