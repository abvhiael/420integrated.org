420 Messenger.

420 Messenger is the ecosystem messaging layer for direct communication, communities and application-linked conversations.

privacy model

Message content is intended to use end-to-end encrypted transport rather than being written publicly to the chain. On-chain records are reserved for the permissions, memberships, subscriptions, treasury relationships and entitlements that need shared verification.

identity & access

420 Identity and related authorization primitives can be reused for account relationships, roles and access control without forcing every message or attachment into permanent public storage.

application integration

Other ecosystem applications can use messaging for notifications, support, communities, transaction context and role-gated communication while relying on shared identity and permission infrastructure.

Final client availability, key-management behavior, transport details and retention policy will be published before public deployment.
