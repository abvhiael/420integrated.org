Architecture / Consensus

consensus & staking.

Consensus is intended to secure block production, validator participation and network finality while staking provides the economic layer around validator eligibility and accountability.

validator responsibilities

Validators are expected to participate in block production, remain available, follow protocol rules and satisfy qualification requirements defined by the network.

staking & slashing

Stake is intended to align validator incentives with network health. Slashing and other penalties are reserved for clearly defined protocol violations and must remain auditable.

governance boundary

Consensus safety and emergency controls are designed to be narrow. Governance should not silently override ordinary protocol execution or validator accounting.

Production validator counts, stake thresholds, reward schedules and slashing parameters remain subject to final genesis configuration.
