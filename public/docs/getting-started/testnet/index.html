Getting started / Testnet

use the testnet first.

The testnet is the qualification environment for wallets, contracts, applications and developer integrations before production genesis.

test assets

The faucet is testnet-only. Test $420 and other test assets have no production value and exist only for development, QA and integration work.

what to test

Developers should verify account creation, RPC connectivity, transaction submission, contract calls, event indexing, explorer visibility and application error handling before production use.

expect resets

Testnet state, addresses and parameters may change during qualification. Applications should not assume pre-genesis test values are permanent.

Faucet URL, testnet chain ID, RPC endpoint and explorer link will appear here when the public qualification environment is available.
