Getting started / Wallet

set up 420 Wallet safely.

420 Wallet is intended to be the primary user interface for accounts, signing, assets and application access across the 420 Integrated ecosystem.

before you install

Only use official release links published on 420integrated.org or the official project repository. Release checksums and signing information will be published with qualified builds.

create or import an account

When wallet builds are released, users will be able to create a new account or import an existing EVM-compatible account where supported. Never share a seed phrase, private key or recovery secret with anyone.

back up recovery material

Store recovery material offline in a secure location. Do not keep your only backup in email, chat, screenshots, cloud notes or another internet-connected service.

verify the network

Before signing transactions, verify the chain ID, RPC endpoint and explorer link against the official network reference.

Production download links and exact wallet setup screens will be added only after release builds are qualified.
