Reference / Network

network parameters.

Canonical network configuration belongs here so wallets, nodes and applications can verify they are connected to the intended environment.

parameter set

Each public environment will publish its chain ID, native currency symbol and decimals, genesis hash, supported RPC endpoints, explorer URL, network name and environment status.

verification

Clients should verify more than an RPC hostname. Chain ID, genesis identity and published environment metadata should agree before an application treats a connection as canonical.

environment separation

Testnet and production parameters will be listed separately. Test assets, endpoints and identifiers must never be assumed to carry production meaning.

Exact chain IDs, genesis hashes and public endpoints remain intentionally unpublished until the corresponding network configuration is qualified.
