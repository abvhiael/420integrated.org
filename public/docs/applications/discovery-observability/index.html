search, analytics & notifications.

420 Search, 420 Analytics and 420 Notifications turn raw ecosystem activity into information people and applications can actually use.

420 Search

Search is intended to provide discovery across indexed ecosystem data, including addresses, transactions, applications, registry records and other supported public resources.

420 Analytics

Analytics provides higher-level views over network and application activity, helping users and operators understand usage, performance and system state without manually reconstructing every event.

420 Notifications

Notifications provide user- and application-facing alerts for events such as transaction state, governance activity, account changes and other subscribed ecosystem events.

Public schemas, indexing coverage, alert channels and retention policies will be documented as these services reach deployment qualification.
